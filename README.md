# NE7 Operations Intelligence Center

An interactive portfolio project exploring IT Operations and Service Delivery through a simulated command center.

## [Open the live dashboard](https://nourbouazza.github.io/it-operations-dashboard/)

## Explore the demo

- **Operations overview:** follow service availability, SLA compliance, incidents, response times and workload.
- **Incident management:** inspect priorities, service impact and incident trends.
- **Service desk:** filter tickets and explore workload and service performance.
- **Digital twin and network:** explore infrastructure dependencies and simulated regional connectivity.
- **Simulation lab:** run scenarios and see their impact across the dashboard.
- **Insights:** explore calculated operational signals and suggested actions.

## About the data

This is a fictional demonstration. Organizations, infrastructure, incidents and metrics are simulated; they do not represent actual service performance. No live monitoring systems are connected.

## About this repository

The published `index.html` is a standalone build of the dashboard. It runs in the browser without installation and is hosted with GitHub Pages.

Built with React, TypeScript, Vite, Recharts and Three.js / React Three Fiber.
